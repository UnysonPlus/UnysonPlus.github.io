# Files on records

Every contact, company and deal page has a **Files** panel for the documents that belong with it: a quote, a
signed contract, a brief, a photo.

## Add files

- **Upload**: choose one or more files (up to ten at once) and click **Upload**.
- **Choose from the media library**: pick files already in WordPress's media library.

Each file shows its name, size and when it was added, and opens in a new tab. The × removes it from the
record; the file itself stays in the media library. Adding and removing files is written on the timeline.

The same file can be on several records, for example a contract on both the company and the deal.

## Good to know

- **Files are ordinary media.** They live in your uploads folder like any image or PDF in WordPress, so
  anyone who has a file's link can open it. Do not upload anything that must stay secret.
- WordPress's allowed file types and maximum upload size apply; the panel shows the size limit.
- Deleting a file from the media library removes it from every record.
- CRM managers and sales reps can upload files on the records they can edit.
