# Data & Content Modeling

Structure your content the way a project actually needs. Unyson+ gives you two building blocks for
this, both built on the same [Options Framework](/options/introduction) as everything else:

- **[Custom Fields](./custom-fields.md)** — ACF-style field groups you attach to post types, built
  from the framework's own option types (text, image, gallery, repeater, relation, and more) and
  rendered as native meta boxes.
- **[Post Types & Taxonomies](./post-types.md)** — register custom post types and taxonomies from the
  WordPress admin, with starter blueprints and import/export, no code required.

They're designed to work together: create a post type, attach a field group to it, then read the
values in a template or bind them to a page-builder element with
[Dynamic Content](/dynamic-content).
