# Chat

<div class="ext-hero">
  <span class="ext-hero__badge">FREE!</span>
  <p class="ext-hero__title">One button, every way to reach you.</p>
  <p class="ext-hero__sub">A floating, multi-channel contact button rendered site-wide — WhatsApp, Messenger, Telegram, SMS, Email or any custom link, configured in Theme Settings.</p>
</div>

Chat adds a floating contact button to every page. Turn on the channels you actually use and the
button adapts:

- **One channel active** → the button is a **direct deep-link** that opens that app or action
  straight away (for example, a WhatsApp chat or a pre-filled email).
- **Several channels active** → the button becomes a **launcher**: tapping it opens a small menu the
  visitor picks their preferred channel from.

## Channels

| Channel | Opens |
| --- | --- |
| **WhatsApp** | A WhatsApp chat with your number (with an optional pre-filled message). |
| **Messenger** | Your Facebook Messenger. |
| **Telegram** | Your Telegram username. |
| **SMS** | A text message to your number. |
| **Email** | A pre-addressed email. |
| **Custom link** | Any URL you want — a booking page, a phone call, a help desk. |

## Set it up

1. Activate **Chat** from **Unyson+ → Extensions** (it ships inactive).
2. Go to **Theme Settings → Site-wide UX → Chat Button**.
3. Enable the channels you want and fill in each one's detail (number, username, address or URL).
4. Save — the button appears site-wide.

:::tip[💡 Web dev tip: fewer choices, faster contact]
A contact button that offers one obvious action converts better than a wall of options. With a
single channel, Chat skips the menu entirely and deep-links straight to it — one tap from "I want to
reach them" to the conversation.
:::

Chat is a **site-wide** control, not a page element: there's nothing to drop into the builder. It's
on every page as soon as it's configured, and off everywhere the moment you deactivate it.
