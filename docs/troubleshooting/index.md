# Troubleshooting & FAQ

Fixes for the issues that come up most, grouped by area, each with the **symptom**, the **cause**, and
the **fix**. Start with the [FAQ](./faq.md) for general questions; jump to a section below for a
specific problem.

## By area

- **[FAQ](./faq.md)** — is it free, do I need a license key, which theme, which PHP, do I have to use
  the builder, how do updates work.
- **[Installation & activation](./installation-and-activation.md)** — requirements, the Classic Editor
  step, downloading the right zip, adding extensions.
- **[Editor & Page Builder](./editor-and-page-builder.md)** — stacked editors, a blank options panel,
  layout not rendering, column wrapping, literal `{{tokens}}`.
- **[Options & settings](./options-and-settings.md)** — "Undefined option type", requirements not met,
  settings overwritten on import.
- **[Importing & converting](./importing-and-converting.md)** — skipped re-imports, missing images,
  restyled admin, disappearing menus.
- **[Updates & versions](./updates-and-versions.md)** — updates not showing up, version rules.
- **[Performance & assets](./performance-and-assets.md)** — the Asset Optimizer scan, a broken combined
  script.

## Still stuck?

- Read the **`AGENTS.md`** nearest the relevant code in the plugin — they're the most detailed,
  continuously-verified references.
- Check the [Hooks reference](/docs/hooks) for a filter that lets you adjust the behavior you're
  fighting.
- File an issue on the relevant [GitHub repo](https://github.com/UnysonPlus).
