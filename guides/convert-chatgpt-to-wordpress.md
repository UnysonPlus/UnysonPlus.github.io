# How to turn a ChatGPT-generated page into a free WordPress site

Asked **ChatGPT** to design a landing page? There are two free ways to turn it into a real WordPress
site with Unyson+.

## Option A — Convert the HTML ChatGPT gave you

ChatGPT usually hands you an **`index.html`** (with its CSS). Bring that into WordPress with the free
**[Site Converter](/extensions/site-converter)**:

1. Save the generated **HTML/CSS** (keep any images alongside it).
2. Install **[Unyson+](/installation)** (free) → activate **Site Converter**.
3. **Unyson+ → Convert** → upload the HTML (or a `.zip`). Full upload walkthrough:
   [Convert an AI-generated HTML site](/guides/convert-ai-generated-html-to-wordpress).

The design lands as editable [page-builder](/page-builder) pages you then extend with posts, forms,
WooCommerce and SEO.

## Option B — Connect ChatGPT to WordPress and build directly

Unyson+'s **AI Assistant** extension exposes an **MCP server**, and ChatGPT's **connectors** can use
it — so ChatGPT can build and edit your site **directly in the page builder**, or run a conversion and
refine it. Set it up under the *Web apps* section of
**[Connect an AI coding tool to your WordPress site](/guides/connect-ai-tools-to-wordpress)**, then see
**[Convert a site to WordPress with an AI agent](/guides/convert-site-to-wordpress-with-ai)** for the
build-and-match loop.

:::tip[Not close enough? Let an AI agent finish the job]
An automatic conversion is a **close, editable starting point — not always pixel-perfect.** To get it
the rest of the way, hand it to an AI agent like **Claude**: it compares the result to your original
section by section and refines it until it matches. See
**[Convert a site to WordPress with an AI agent](/guides/convert-site-to-wordpress-with-ai)**.
:::

## FAQ

**Is it free?** Yes — Unyson+, the Site Converter and the AI Assistant MCP server are free. ChatGPT is
your own account.

**Which option should I use?** Convert (Option A) if you already have the HTML; connect ChatGPT over a
connector (Option B) if you want it to build and refine the site for you.
