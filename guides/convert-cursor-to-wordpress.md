# How to build a WordPress site with Cursor (free)

**Cursor** is an AI code editor — and there are two free ways to turn what you build in it into a real
WordPress site with Unyson+, depending on what you want.

## Option A — Connect Cursor to WordPress and build directly (recommended)

Unyson+'s **AI Assistant** extension exposes an **MCP server**, so Cursor can build and edit your site
**directly in the page builder** — create pages, set Theme Settings, and even run a site conversion
and refine it. It's the most hands-off path.

1. Set Cursor up against your site: **[Connect an AI coding tool to your WordPress site](/guides/connect-ai-tools-to-wordpress)** (Cursor section).
2. Then just ask it — *"build a draft landing page with these sections"*, or point it at a design to
   convert and refine. The full convert-and-match loop is in
   **[Convert a site to WordPress with an AI agent](/guides/convert-site-to-wordpress-with-ai)**.

## Option B — Convert a page you coded in Cursor

If you've built a static page in Cursor, bring the design into WordPress with the free
**[Site Converter](/extensions/site-converter)**:

1. **Deploy it** to a public URL and convert **[from the URL](/extensions/site-converter/convert-from-url)**, or
2. **Convert the HTML/CSS** your project produces — see
   [Convert an AI-generated HTML site](/guides/convert-ai-generated-html-to-wordpress).

Either way the design lands as editable [page-builder](/page-builder) pages you then extend with
posts, forms, WooCommerce and SEO.

:::tip[Not close enough? Let an AI agent finish the job]
An automatic conversion is a **close, editable starting point — not always pixel-perfect.** To get it
the rest of the way, hand it to an AI agent like **Claude** (or Cursor itself over MCP): it compares
the result to your original section by section and refines it until it matches. See
**[Convert a site to WordPress with an AI agent](/guides/convert-site-to-wordpress-with-ai)**.
:::

## FAQ

**Is it free?** Yes — Unyson+, the Site Converter and the AI Assistant MCP server are free. Cursor is
your own editor/subscription.

**Which option should I use?** Connect over MCP (Option A) if you want Cursor to build and refine the
site for you; convert (Option B) if you already have a page and just want it in WordPress.
