# Free WordPress templates

Most "free WordPress templates" you find are either a **static theme** you can't easily rearrange, or
a teaser for a paid page-builder bundle. **Unyson+** takes a different route: it's a **free** page
builder with a built-in **Template Library** of ready-made sections and whole pages that you **drop
onto the canvas and edit** like any other content — no pro tier, no license key, no code.

This guide shows the three free ways to get a template into your site and make it your own:

1. **Insert a premade template** from the Template Library.
2. **Save your own** section or page as a reusable template.
3. **Turn any design** (an existing site, or an AI-generated layout) into a template with the Site
   Converter.

## What you get (and why it's actually free)

- A **drag-and-drop [page builder](/page-builder)** that outputs clean, native WordPress content —
  not a locked proprietary format.
- A **Template Library**: a browsable catalog of premade **sections** (hero, stats band, testimonials,
  pricing, CTA…) and **whole pages**, downloaded on demand so the plugin stays lean.
- **Global Templates**: reusable sections that stay in sync across every page.
- No "unlock this in Pro" walls — Unyson+ and its extensions are free.

:::note[One-time setup]
Install and activate **[Unyson+](/installation)** (free). The template catalog ships in the
**Template Library** extension — turn it on under **Unyson+ → Extensions** (it pulls in the page
builder automatically).
:::

## Option 1 — Insert a premade template

1. Edit any page and open the **Page Builder**.
2. Click the **Templates** menu (top-right of the builder).
3. Browse **Sections** or **Pages**, pick one, and it drops onto the canvas **ready to edit**.
4. Click any element to change its text, images, colors and layout — it's normal builder content now,
   not a frozen design.

Because a template is just page-builder content, it automatically picks up **your** site's
[global colors and fonts](/guides/global-colors-and-fonts) — so a dropped-in section looks like
*your* brand, not a stock demo.

## Option 2 — Save your own template (reuse your best sections)

Built a section you love? Keep it:

1. In the builder, hover a **Section** or **Column** and click **Save as Template**.
2. Give it a name. It now appears under the **Templates** menu's **Load Template** list, ready to
   insert on any page — each insert is an independent copy you can tweak freely.

### Make it a *synced* template

If you want one section — a footer CTA, a contact band — to stay **identical everywhere**, turn on
**Save as Global Template** in that same dialog. Every page then references one source, so editing it
once updates them all. Full details: **[Global Templates](/extensions/global-templates)**.

:::tip[💡 Copy-paste doesn't scale]
Pasting the same hero onto twenty pages means twenty places to fix when the phone number or offer
changes — and it's easy to miss one. A **Global Template** is the content version of a CSS custom
property: define it once, reference it everywhere, edit in one place.
:::

## Option 3 — Turn any design into a template

Have a design somewhere else — an old site, a one-page HTML export, or a layout an AI builder made?
The free **[Site Converter](/extensions/site-converter)** rebuilds it as **native, editable**
page-builder content, which you can then **Save as Template** and reuse. That turns "a design I like"
into "a template I own," for free. See
**[Convert an existing website to WordPress](/guides/convert-website-to-wordpress)**.

## FAQ

**Are the templates really free?**
Yes. Unyson+, the page builder and the Template Library are free — there's no pro tier gating the
templates.

**Can I edit a template, or is it locked?**
Fully editable. A template inserts as ordinary builder content — change text, images, colors, spacing
and structure like anything else.

**Do templates match my theme's colors and fonts?**
Yes — they use your [global colors and fonts](/guides/global-colors-and-fonts), so an inserted
section adopts your brand automatically.

**What's the difference between a Template and a Global Template?**
A **Template** inserts an independent copy each time. A **Global Template** inserts a synced
*reference* — edit it once and every page updates. Pick per use.

**Where are downloaded templates stored?**
In your WordPress uploads folder, not inside the plugin — so adding templates never bloats the
plugin.
