# Roadmap

This page lists only the work that is still to come. Kinetic Scenes was built over 29 phases, from the scene file and
the player to the editor, export, AI, 3D, sound, video mode, screencasts, mascots and page animation, and those
features are now described on the [guide pages](./index.mdx) rather than here. When a task below is finished, it moves
off this page and onto the guide page for that feature.

The Studio is in beta at [kinetic-scenes.unysonplus.com](https://kinetic-scenes.unysonplus.com/).

## What comes next

1. **Four new motion styles.** Stick figures, a voxel build, a 3D map route and a "what if" 3D explainer: looks that
   the other 43 [motion styles](./motion-styles.md) don't cover yet. Each gets the same treatment as the existing ones:
   a style card, a guide for the AI, a docs page and an entry in What's new.
2. **Still open from earlier phases.** Loading media only when the playhead nears it, a benchmark against hand-made
   videos, and two ways to learn from a video link.
3. **Later, only if people ask.** Saving projects to Google Drive, and accounts with cloud projects.

The plan and the reasons behind it are on the [overview](./index.mdx); what already exists elsewhere is on the
[research](./research.md) page.
