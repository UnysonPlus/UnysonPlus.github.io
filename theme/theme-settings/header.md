# Header

The **Header** tab builds the site header across several sub-tabs: Identity, Layout, Menu, Top Bar,
Main Header, and Bottom Bar.

## Identity (logo)

**Header → Identity** (`header_logo`) offers two logo builders via a **Logo Type** picker:

- **Simple** — an uploaded image logo, with variants for retina (2×), the sticky header, mobile, and a
  transparent/overlay header, plus a display **width** and alt text. Two-way synced with WordPress's
  Custom Logo.
- **Custom** — a text wordmark: **Site Title** (+ size, weight, color), an optional **tagline**, and an
  optional **logo icon** (inline SVG) with a frame (rounded / squircle / circle / hexagon…) and a
  **layout** (inline, stacked, or eyebrow arrangements).

The **Favicon / Site Icon** is always available and syncs with WordPress's Site Icon.

## Layout modes

**Header → Layout** (`header_layout`) picks the overall **Header Layout Mode**:

| Mode | What it is |
| --- | --- |
| **Top** | The standard horizontal header. |
| **Vertical** | A fixed side rail (choose left or right). |
| **Off-canvas only** | A hamburger that opens a slide-in panel, with no persistent bar. |
| **Overlay** | The header sits transparent over the hero. |

### Header designs (Top mode)

In Top mode, a **Header Design** picker gives the bar its structural treatment:

- **Classic** — a full-width bar.
- **Pill** — a rounded floating bar, with radius, side inset, and shadow controls.
- **Card** — a floating card with corner radius and shadow.
- **Centered** — logo centered above the menu, with a spacing control.

The remaining sub-tabs (Menu, Top Bar, Main Header, Bottom Bar) configure the rows and the navigation
inside the chosen mode.
